# Lanternroom — project brief

Lanternroom is a personal, phone-first AI character chat app (an alternative to Janitor AI) built for its owner, **Fethurz**. It runs entirely in the browser and is published with **GitHub Pages** from this repo.

- Live site: https://fethurz.github.io/Lanternroom/
- **The whole app is one file: `index.html`** (HTML + CSS + JS, no build step, no dependencies besides Google Fonts), plus the installable-app files: `manifest.webmanifest`, `sw.js` (service worker) and `icons/` (lantern icons: 192, 512, maskable 512, apple-touch 180, svg; rendered by scratch `mkicons.js`).
- **Installable app (PWA, v1.24):** Android Chrome installs it to the home screen (full-screen, own icon, offline start). `sw.js`: the page is network-first (updates land on the next open; cached copy when offline), built-in sounds/icons/fonts cache-first (`lr-media-1`), sound manifests stale-while-revalidate; cross-origin (DeepSeek, Supabase, Pollinations) and Range requests are never touched. Bump `SHELL`/`MEDIA` cache names in `sw.js` only to force-drop old caches. Settings → Look → App shows Install (via `beforeinstallprompt`) or how-to (computer wording for fine pointers: Chrome/Edge install icon). **PC program (v1.40):** the same PWA installs on Windows from Chrome/Edge as a program (own window, Start menu/taskbar). Manifest `launch_handler` focus-existing, `shortcuts` (./?open=last|new|settings, handled at the end of boot), `file_handlers` (.zip, .json, .png) → `launchQueue` → `openFiles(files)` (zips/audio → `importSounds`, cards → `importCardFile`); files dropped on Home do the same; Esc closes the sound panel, then a window (`userClose`), then leaves the chat. `BOOTED` promise resolves when boot finishes. **Windows program (v1.41):** Opera GX can't install PWAs, so there's an Electron wrapper (source in the repo since v1.42: `desktop/main.js` and `desktop/mkinstaller.py`; scratch copies get lost between sessions. Electron v42.3.0 win32-x64 from GitHub releases, checksum-verified; `main.js` opens https://fethurz.github.io/Lanternroom/ in one remembered window, other sites open in the default browser, autoplay allowed, camera allowed, F11/Ctrl±/Ctrl R, `setAppDetails` + first-run desktop/Start-menu shortcuts with `icon.ico`; electron.exe renamed Lanternroom.exe, no npm (registry blocked)). The 137 MB zip was too big to send in chat (30 MB limit) and a GitHub release was refused, so the owner gets `Install Lanternroom.cmd` (`python3 desktop/mkinstaller.py out.cmd`, ~109 KB; never commit the built .cmd): a .cmd that runs embedded PowerShell to download Electron from GitHub, check its SHA-256, unpack to %LOCALAPPDATA%\Lanternroom, write main.js/package.json/icon.ico, add desktop + Start menu shortcuts and start it. Tested with pwsh 7 on Linux (env LR_DEST/LR_ZIP/LR_NOSHORTCUTS/LR_NOSTART for dry runs: extract the text after the last `#PSBEGIN` and `iex` it); main.js is smoke-tested in Linux Electron v42.3.0 under xvfb with `--no-sandbox --remote-debugging-port` and Playwright `connectOverCDP` (github.io is unreachable from the workspace, so the offline retry page shows). **v1.42 sound fix:** main.js switches `disable-features=CalculateNativeWinOcclusion`, `disable-renderer-backgrounding`, `disable-background-timer-throttling`, `disable-backgrounding-occluded-windows`, `webPreferences.backgroundThrottling: false`; offline → small retry page (`did-fail-load`); F5 reloads too; camera/notification/clipboard permissions only for the site's origin. The page side: `away()` = hidden *and* not focused; `acx()`/`wakeAudio()` resume the AudioContext on focus, pageshow, any state change and a 3 s check. The owner must rerun the installer once to get the new wrapper. Running it again reinstalls/repairs. It loads the live site, so app updates arrive on their own. Install text detects Electron and Opera. Back button: `syncNav()` keeps one history entry while a sheet/chat is open (MutationObservers on `#sheet`/`#chat` `hidden`); popstate closes the sound panel, then the sheet, then the chat (`leaveChat()`); exits from Home.
- **Publishing:** commit to `main` → GitHub Pages redeploys in ~1–2 minutes. Phones may cache the old page for a few minutes; the owner checks the version at the bottom of Settings.
- **Bump `VERSION`** (near the top of the script, e.g. `"1.9 · Oct 12"`) with every release so the owner can confirm the update landed.
- The owner uses the app on an Android phone and talks to Claude from the Claude mobile app. Keep explanations short and non-technical; they are not a programmer.

## Owner's rules for Claude (always follow)
- **Never read the owner's chats** (the `c2:` / `chats:` rows in Supabase, or chat contents anywhere) unless the owner has given explicit permission for a specific bot's chat, or Claude asked first and the owner said yes. A "no" is final. Test with made-up chats instead. Bot cards (`chars`), settings and sound lists are fine to read when needed.
- **Content rules are the owner's to write.** The app sends no content restrictions of its own (no forced safe-for-work in images or prompts) except one: every character is an adult. Since v1.50 the text-model wording (owner's choice, so sentient objects and creatures read naturally) is "Every character is treated as a fully grown, mature being" (the hidden line in `GEN_SYS`, "Fully grown and mature" / "apparent age (fully grown and mature)" in the appearance-description prompt); image prompts keep the plain word "adult" (portrait/illustration prompts, the illustration writer's "Every character is an adult."). Quiz ages stay adult ranges / 18+. Keep that; add nothing else.

## Owner preferences and conventions
- Mobile first: everything must work at ~390 px wide; tap targets ≥ 34 px.
- Dark, warm look: deep purple-black background, amber accent (`--accent #e8a95b`), fonts Young Serif (display) + Atkinson Hyperlegible (body). The **lantern** is the app's identity.
- Prefers compact layouts, tabs over long scrolling lists, and subtle animation.
- Ships features in batches; test them before pushing (see Testing).
- Adult content is part of the app (vore, scat, sexual sound effects). Build what the owner asks for within Claude's guidelines and say plainly if something can't be done.
